# Экотория — клон сайта с админкой-конструктором

Полноценная копия сайта [https://ekotoriya.ru/](https://ekotoriya.ru/) на Python + Flask
с визуальной админ-панелью для управления страницами, блоками, товарами и заказами.

## Возможности

- 32+ страницы (главная, каталог, блог, компания, помощь, контакты, документы и др.).
- Визуальный конструктор страниц: заголовки, текст, изображения, галереи, преимущества,
  формы, таймеры, баннеры, Zero-блоки, таблицы, FAQ, карты, отзывы и др.
- Черновики / публикация / история версий страниц.
- Каталог товаров с синхронизацией Wildberries / Ozon, скидками, фильтрами, корзиной.
- Клиентская база: профили, история заказов, избранное, рекомендации, чат с магазином.
- SEO: meta-теги, canonical, хлебные крошки, JSON-LD.
- Загрузка файлов, медиатека, локальный image-cache.

## Требования

- Python 3.11+
- SQLite (используется локально)
- Docker + Docker Compose (опционально, для production-развёртывания)

## Установка и запуск

```bash
# 1. Создать виртуальное окружение
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Применить миграции базы данных (создаётся data/ekotoriya.db)
alembic upgrade head

# 4. Запустить сайт
python app.py
```

Откройте в браузере:

- **Сайт:** http://127.0.0.1:5000/
- **Админка:** http://127.0.0.1:5000/admin

## Доступ в админку

Первый запуск создаёт файл `data/admin_credentials.json` со стандартным паролем.
Рекомендуется задать логин/пароль через переменные окружения **перед первым запуском**:

```bash
set ADMIN_USER=admin
set ADMIN_PASS=надежный_пароль
python app.py
```

(на Linux/macOS используйте `export` вместо `set`).

После первого входа система потребует сменить пароль.

## Роли и безопасность

- **Суперадмин** — полный доступ, включая настройки синхронизации, пользователей,
  смену пароля, HTML/CSS-блоки.
- **Редактор** — создание/редактирование страниц и блоков, без доступа к настройкам
  и синхронизации.
- CSRF-токены, проверка ролей, санитайзинг загрузок, ограничения на inline-CSS.

## Тесты

```bash
pytest tests/
```

Для изолированного прогона используется SQLite в памяти (`DATABASE_URL` из `conftest.py`).

## Редактор страниц

1. В админке выберите страницу и нажмите «Редактировать».
2. Добавляйте, перемещайте, дублируйте и настраивайте блоки.
3. Используйте «Предпросмотр» перед публикацией.
4. Нажмите «Опубликовать», чтобы изменения стали видны посетителям.
5. При конфликте версий редактор покажет предупреждение (опционально).

## Данные

- `data/ekotoriya.db` — SQLite-база: страницы, блоки, версии, товары, заказы, клиенты.
- `data/content.json` — фолбэк-источник контента (используется, пока в БД нет страниц).
- `data/section_presets.json` — пресеты секций для визуального редактора.
- `data/image_cache/` — локальный кэш проксированных изображений (создаётся автоматически).
- `static/upload/` — загруженные пользователем файлы.

## Синхронизация товаров

В админке «Настройки → Интеграции» можно указать токен WB API и seller ID для
автоматической загрузки карточек. Для Ozon — соответствующий API-ключ.
Поддерживается демо-режим (`WB_DEMO=1`) без реальных API-вызовов.

## Резервное копирование и восстановление

Перед крупными изменениями создавайте бэкап каталога `data/` и кода:

```bash
# ручная копия
cp data/ekotoriya.db data/ekotoriya.db.backup
tar -czf backup_$(date +%Y-%m-%d).tar.gz data/ekotoriya.db data/content.json data/section_presets.json static/upload
```

Для восстановления замените файлы из бэкапа и перезапустите приложение.

```
.
├── app.py                 # Flask-приложение: роуты, админка, API, рендер блоков
├── blocks.py              # Серверный рендер блоков конструктора

├── models.py              # SQLAlchemy-модели
├── alembic/               # Миграции БД
├── data/
│   ├── ekotoriya.db       # Рабочая SQLite-база
│   ├── content.json       # Фолбэк-контент
│   ├── section_presets.json
│   └── image_cache/       # Локальный кэш изображений
├── static/                # CSS, JS, изображения, шрифты
├── static/js/page-editor.js # Клиентский редактор блоков
├── templates/
│   ├── pages/             # Jinja2-шаблоны страниц
│   └── admin.html         # Шаблон админ-панели
├── tests/                 # Pytest-тесты
├── docker-compose.yml     # Production-развёртывание
└── requirements.txt
```

## Известные ограничения

- Сайт ориентирован на локальный запуск и простое Docker-развёртывание.
- Онлайн-оплата, email-рассылки и SMS не реализованы.
- Внешний вид критических страниц сверяется с оригиналом ekotoriya.ru вручную.
