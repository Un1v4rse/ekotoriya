# Экотория — многостраничный клон сайта с админкой

Полноценная копия сайта [https://ekotoriya.ru/](https://ekotoriya.ru/) на Python + Flask с простой админ-панелью для управления страницами.

## Возможности

- 32 основные страницы: главная, каталог, блог, компания, помощь, контакты, политика конфиденциальности и др.
- Все статические активы (CSS, JS, изображения, шрифты) сохранены локально.
- Роутинг Flask для любого slug из `data/content.json`.
- Админ-панель для редактирования:
  - любой страницы (title, H1, meta description, HTML контента);
  - общих настроек сайта (телефон, email, адрес, логотип);
  - меню и социальных сетей (JSON);
  - загрузки файлов и пересборки шаблонов из исходников.

## Быстрый старт

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Запустить сайт
python app.py
```

Откройте в браузере:
- **Сайт:** http://127.0.0.1:5000/
- **Админка:** http://127.0.0.1:5000/admin

## Доступ в админку

- **Логин:** `admin`
- **Пароль:** `admin`

Пароль можно изменить через переменную окружения:

```bash
set ADMIN_PASS=новый_пароль
python app.py
```

## Пересборка из оригинала

Если нужно заново сгенерировать шаблоны из скачанных файлов в `static_original/pages/`:

```bash
python build_template.py
```

> Скрипт перезапишет `data/content.json` значениями по умолчанию.

## Догрузка недостающих активов

Чтобы проверить и скачать недостающие CSS/JS/изображения, указанные в шаблонах:

```bash
python download_assets.py
```

## Структура проекта

```
.
├── app.py                 # Flask-приложение с многостраничным роутингом
├── build_template.py      # Скрипт генерации шаблонов из static_original/pages/
├── download_assets.py     # Дозагрузка недостающих static assets
├── data/
│   └── content.json       # Редактируемый контент всех страниц
├── static/                # Локальные CSS, JS, изображения, шрифты
├── static_original/       # Исходные файлы, скачанные с ekotoriya.ru
│   └── pages/             # Сырые HTML страницы
├── templates/
│   ├── pages/              # Готовые Jinja2-шаблоны каждой страницы
│   └── admin.html         # Шаблон админ-панели
└── requirements.txt       # Зависимости Python
```

## Примечания

- Сайт построен на основе сохранённых статических файлов оригинала.
- Динамические функции Битрикс (корзина, поиск, заказы, личный кабинет) не работают — это статический клон визуальной части.
- Видео подгружаются с внешних источников (VK, RuTube и т.п.).

## Требования

- Python 3.8+
- Flask 2.0+
