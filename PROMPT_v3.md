## Критичные требования к конструктору

- Трёхзонный layout: **левая панель** (библиотека блоков: категории, превью, поиск, drag-and-drop добавление), **холст** (страница как на сайте), **правая панель** (настройки выбранного блока по вкладкам). Верхняя панель: undo/redo, предпросмотр desktop 1200 / tablet 768 / mobile 360, настройки страницы, статус черновик/опубликовано, сохранить/опубликовать.
- Настройки блока по вкладкам: Контент, Фон (цвет/картинка/градиент/видео/parallax), Расположение (отступы, ширина), Типографика (шрифты Google Fonts, размер, цвет, интерлиньяж, трекинг, начертание, выравнивание — на уровне блока и элемента), Кнопка (стили, скругление, тень, hover), Эффекты (анимация появления, sticky, декор, responsive-visibility), Дополнительно (CSS-класс; свой CSS — только суперадмин).
- Инлайн-редактирование текста с мини-тулбаром (bold/italic/ссылка); клик по блоку — правая панель.
- Глобальные зоны шапки/подвала (редактируются один раз для всех страниц; sticky; прозрачность; меню с вложенностью; переопределение на странице).
- Тема: палитра, шрифтовые пары Google Fonts (поиск/предпросмотр), шкала H1–H6, базовый текст, радиусы, тени, стили кнопок по умолчанию, пресеты, история с откатом, живой предпросмотр. Блоки по умолчанию используют переменные темы.
- Zero-блок: абсолютное позиционирование элементов (текст/кнопка/картинка/фигура/видео/иконка), слои, drag/resize/поворот, адаптивные контрольные точки.
- «Мои блоки» + шаблоны страниц (лендинг/витрина/контакты); версии страниц (мин. 10, откат); черновик/публикация (draft_blocks/published_blocks, миграция: текущие blocks = published).
- Производительность: без лагов на 30+ блоках; точечные обновления DOM, debounce; горячие клавиши (Ctrl+Z/Y, Delete, Esc, стрелки в Zero).
- Серверные API из CN-T12 (все, с CSRF); рендер всех новых полей в `blocks.py` с валидацией и fallback к дефолтам; **никакой инъекции через настройки блока**.
- Обратная совместимость: существующие страницы/блоки открываются и редактируются в новом редакторе без потери данных.
