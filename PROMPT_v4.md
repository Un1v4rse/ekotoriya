Zoom, режим «во всю ширину», авто-коллапс панелей на узких экранах — всё описано в плане.
2. **Дублирующий «странный» редактор в админке — удалить.** Решение — строго по Этапу 2 (CN-D): остаётся ОДИН редактор (Tilda-редактор цикла 2) с двумя точками входа (список страниц в админке + кнопка на самой странице для админа). Второй UI-редактор удалить полностью (шаблоны/JS/CSS/маршруты/кнопки), **общие серверные API `/admin/api/*` не трогать**.

## Жёсткие требования

- **Canvas/scale**: страница на холсте видна целиком при любой ширине окна; pointer-события (клики, drag-and-drop, выделение, resize) корректны при любом zoom — координаты делить на scale. Горизонтального скролла холста нет.
- **Один редактор**: ни один URL не должен открывать удалённый UI; обе точки входа ведут в единый редактор; мёртвый код вычищен grep-проверкой.
- **Не ломать**: цикл 1 (БД, Ozon, скидки, каталог, рекомендации, ЛК, безопасность) — только фикс регрессий по факту.
- **Обратная совместимость данных**: существующие страницы открываются и редактируются без потерь; схему блоков расширять, не ломать.
- **Правила прежние**: бэкапы (макс. 3, ротация), WORKLOG после каждой задачи, pytest зелёный, без вопросов (решения — в WORKLOG), ничего сверх ТЗ (оплата, рассылки, SMS — не делать).
