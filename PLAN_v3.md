## ЭТАП 1. ВЁРСТКА ХОЛСТА: страница всегда видна целиком (CN-L) — КРИТИЧНО

> Требование заказчика: «сама страница не влезает в блок — сайдбары её урезают. С этим нужно что-то придумать».
> Решение — как у Tilda/Framer/Webflow: фиксированные сайдбары, холст — оставшаяся ширина,
> страница на холсте масштабируется scale-to-fit. НИКАКОГО горизонтального обрезания страницы.

- [x] 1.1 (2026-09-25) **Grid редактора**: левая панель 280px, правая панель 340px, центр — холст. Обе панели **сворачиваемые** (кнопка-«шеврон»; состояние запоминается в localStorage). Сайтбары — `flex: 0 0 auto`, холст — `flex: 1 1 auto`, `overflow: auto` только вертикальный.
- [x] 1.2 (2026-09-25) **Scale-to-fit**: ширина страницы на холсте = ширине контейнера сайта (из темы, по умолчанию 1200px). Вычислять `scale = min(1, canvasWidth / pageWidth)` и применять `transform: scale()` к обёртке страницы; обёртке задать `width: pageWidth; transform-origin: top center; margin: 0 auto;` и высоту, скомпенсированную делением на scale. Страница всегда полностью видна по горизонтали, прижата к верху, горизонтального скролла холста НЕТ.
- [x] 1.3 (2026-09-25) **Индикатор и ручной zoom**: в топбаре/статусбаре холста — текущий масштаб %, клик по нему или Ctrl+колесо — зум 50–100% с шагом 10, кнопка «по ширине» (сброс к scale-to-fit). Изменение размеров окна/панелей пересчитывает scale (debounce ~100ms, ResizeObserver).
- [x] 1.4 (2026-09-25) **Режим «Во всю ширину»** (toggle в топбаре): страница растягивается на `canvasWidth` без масштаба (для правки широких блоков). Состояние — в localStorage.
- [x] 1.5 (2026-09-25) **Авто-коллапс на узких экранах**: при ширине окна < 1440px правая панель по умолчанию открывается **оверлеем поверх холста** (не сжимая его; подложка-затемнение, Esc/клик по подложке закрывает). Левая панель — авто-свёрнута. Холст всегда ≥ 360px; ниже — подсказка «сверните панели».
- [x] 1.6 (2026-09-25) Клики/драг внутри масштабированной страницы должны работать корректно (учитывать scale в координатах pointer-событий: делить clientX/Y на scale; drag-and-drop блоков, выделение, resize — всё обязано работать при любом zoom). Проверить весь существующий функционал редактора под масштабом ≠ 100%.
- [x] 1.7 (2026-09-25) **Проверка вручную** на 1920 / 1440 / 1280 / 1024px ширины окна: страница полностью видна, выровнена по центру, скролл только вертикальный; панели сворачиваются; оверлей работает. Скриншоты/описание — в WORKLOG.

**DoD:** при любой ширине окна и любом состоянии панелей страница на холсте видна целиком, ничего не урезано; drag/drop/клики работают при любом масштабе.
