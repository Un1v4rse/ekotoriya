# BACKUPS — реестр резервных копий

Правило: не более трёх активных бэкапов. Новый бэкап создаётся перед каждым
глобальным изменением; самый старый удаляется только после успешного создания
нового.

| Дата | Commit | Причина | Состав | Проверка |

| 2026-10-31 22:05 | 6e6a894 (+ незакоммиченные правки формы) | Перед завершением Приоритета 2 (endpoint /api/form + UI) | src.tar 167M + ekotoriya.db 14M | Архив создан, БД скопирована |
| 2026-10-31 23:00 | b0ffb97 | Перед Приоритетом 3 (адаптивность) | src.tar 167M + ekotoriya.db 14M | Архив создан, БД скопирована |
| 2026-10-31 23:35 | b0ffb97 (+ незакоммиченные правки адаптивности) | Перед Приоритетом 4 (Zero-редактор) | src.tar 167M + ekotoriya.db 14M | Архив создан, БД скопирована |

Команды восстановления:
```bash
# распаковка кода
tar -xzf backups/backup_ДАТА/src.tar -C ..
# восстановление БД
cp backups/backup_ДАТА/ekotoriya.db data/ekotoriya.db
```

Последний бэкап актуален на текущее рабочее состояние.
