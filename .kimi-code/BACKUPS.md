# BACKUPS — реестр резервных копий

Правило: не более трёх активных бэкапов. Новый бэкап создаётся перед каждым
глобальным изменением; самый старый удаляется только после успешного создания
нового.

| 2026-10-31 23:45 | 01dbc47 | Перед началом работы над Zero | src.tar 167M + ekotoriya.db 14M | Архив создан, БД скопирована |
| 2026-11-01 00:00 | ed2233a | Перед Приоритетом 5 (черновики / версии / конфликты) | src.tar 167M + ekotoriya.db 14M | Архив создан, БД скопирована |

Команды восстановления:
```bash
# распаковка кода
tar -xzf backups/backup_ДАТА/src.tar -C ..
# восстановление БД
cp backups/backup_ДАТА/ekotoriya.db data/ekotoriya.db
```

Последний бэкап актуален на текущее рабочее состояние.
